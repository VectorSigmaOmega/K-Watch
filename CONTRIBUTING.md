# Contributing to K-Watch

Thank you for your interest in K-Watch!

## Development Process

1. Fork the repository and create a new branch.
2. Ensure your changes compile cleanly under both GCC and Clang.
3. Run `clang-format` on your code before committing.
4. Ensure `clang-tidy` reports no new warnings.
5. Create a Pull Request with a clear description of your changes.

See the PRD for architectural constraints and roadmap.
