================================================================================
PROJECT 2: K-WATCH (EBPF KERNEL OBSERVABILITY ENGINE)
================================================================================
GOAL: A tool that injects code into the Linux Kernel to monitor and filter network traffic.

CORE DELIVERABLES:
- Kernel-space program (C) to hook into XDP (Express Data Path).
- User-space loader (C++) to read kernel metrics and display a dashboard.
- A "Kill-Switch" feature to block specific IP addresses in the kernel.

TECHNICAL REQUIREMENTS:
- Kernel Side: `SEC("xdp")` program using `struct xdp_md`.
- Communication: BPF Maps (`BPF_MAP_TYPE_HASH` or `BPF_MAP_TYPE_RINGBUF`).
- Library: `libbpf` for loading and attaching the program.
- Performance: Must handle packets at the driver level before they reach the CPU stack.

IMPLEMENTATION PHASES:
1. Kernel Code: Write a C program that parses Ethernet/IP headers and increments a counter in a BPF map.
2. User-space Loader: C++ program using `libbpf` to load the `.o` file.
3. Visualization: A simple terminal loop that clears the screen and prints live packet counts per protocol.
4. Interaction: Add a feature to write an IP to a "Blacklist" BPF map from user-space.
